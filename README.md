# The Frictionless Learning Paradox
### Hackoverflow 10.0 Submission

## 🧠 Project Overview
An AI-powered EdTech prototype designed to introduce "desirable difficulty" and prevent cognitive cushioning in student learning.

## 📁 Repository Contents
- `app.py`: The main Streamlit web application interface.
- `friction_engine.py`: Core logic module for evaluating student effort and triggering Socratic guidance.

## 🚀 How to Run Locally
1. Install dependencies: `pip install streamlit`
2. Run the app: `streamlit run app.py`
